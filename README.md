# medlead-ai-agent
An AI-powered patient booking and qualification receptionist agent for dermatology and laser clinics, built with zero-hallucination and Egyptian Arabic operational flow.
## 🎯 Overview & Purpose
MedLead is a specialized conversational AI agent designed to act as a 24/7 intelligent receptionist and booking specialist for dermatology, cosmetology, and laser clinics in Egypt.

✨ Key Features

- **Egyptian Arabic Tone**:

 Communicates naturally and warmly using friendly local phrasing.

- **Zero-Hallucination Policy**:

 Strictly prevents guessing or making up medical advice, prices, or unlisted services.

- **Direct Doctor Escalation**:

 Automatically redirects medical or unlisted inquiries to direct consultations.
- **Smart Lead Qualification**:

 Seamlessly collects the 4 essential booking parameters (Full Name, Phone Number, Preferred Doctor, and Date & Time).

# How to Run / Test in Under 5 Minutes
1. Copy the contents of `prompt.txt`.
2. Paste it into your AI agent configuration platform as the System Prompt.
3. Attach the clinic reference documents (services & pricing list).
4. Start testing the chat with natural patient scenarios!
